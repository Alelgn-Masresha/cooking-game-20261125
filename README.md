**Lantern Noodle Bar**: a night-market noodle stall cooking game for desktop browsers. Boil noodles before
they go soggy, chop scallion, mushroom and chili, ladle broth, build each bowl to match a ticket on the
order rail and carry it to the pass before the customer gives up. Three-minute shifts, a dinner rush that
speeds up and unlocks new recipes, tips for speed and a streak bonus.

Mouse: click stations. Keys: 1-7 crates, B broth, Space chop, A/S pots, Q/W/E bowls, Enter serve, X bin, P pause, M mute.

All art is drawn in code and all sound is synthesised; no assets, no libraries, no network.

## Run it

```sh
node serve.ts        # then open http://localhost:8080 in desktop Chrome
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts   # hand-in: game/, screenshots/, dossier.json
node tools/capture.mjs                                # re-take the screenshots from ?shot= scenes
```
